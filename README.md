# CampusConnect

A Java-based student and campus management system built to practice software engineering, object-oriented programming, data structures, and clean project design.

## Version 1 — Core Java

CampusConnect is currently being developed as a console-based application.

### Planned features

- Add students
- View students
- Search students
- Add courses
- View courses
- Enroll students in courses
- View enrollments
- Exit the application

## Tech Stack

- Java
- Object-Oriented Programming
- Java Collections
